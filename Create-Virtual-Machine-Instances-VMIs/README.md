## 🧠 Key Concepts

| 🔑 Concept | 📖 Description |
|-----------|---------------|
| **Virtual Machine Instance (VMI)** | The running instance of a virtual machine on OpenShift Virtualization |
| **YAML Manifest** | Declarative definition used to create VMIs with different configurations |
| **CPU Specification** | Cores, sockets, threads, and CPU features configured for performance optimization |
| **Hugepages** | Memory configuration option for workloads with specific memory requirements |
| **PVC (PersistentVolumeClaim)** | Provides durable storage for VMIs |
| **VM Lifecycle** | Start, stop, pause, and restart operations and the VMI states and transitions involved |
| **Network Policy** | Security boundary controlling network access for VMIs |
| **Resource Quota** | Security boundary limiting resource consumption |
| **Custom Scheduling** | Control over where VMIs are placed |
