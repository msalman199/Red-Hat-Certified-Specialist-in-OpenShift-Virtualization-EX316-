## 📖 Overview

This lab covers **advanced VM cloning techniques** using open-source virtualization tools. You created full and linked clones with `virsh` and `qemu-img`, customized clones with different hardware, network, and storage settings, automated cloning with shell scripts and configuration templates, and used cloud-init for automated VM customization.

> 🧪 **Lab Environment:** Virtualization environment with open-source tooling (`virsh`, `qemu-img`, cloud-init). Work is done from the command line with shell scripts and configuration templates.

## 🔑 Key Concepts

| 🏷️ Term | 📘 Description |
|---|---|
| **Full Clone** | Complete, independent copy of a VM and its disk |
| **Linked Clone** | Clone that shares storage with its base image, minimizing storage requirements |
| **virsh** | CLI tool used to create and manage clones |
| **qemu-img** | Tool used to create and manage clone disk images |
| **cloud-init** | Mechanism for automated VM customization at deployment |
| **Configuration Template** | Reusable settings that drive automated, reproducible cloning |
