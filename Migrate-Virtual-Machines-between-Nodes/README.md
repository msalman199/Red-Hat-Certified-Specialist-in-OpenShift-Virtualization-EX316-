## 📖 Overview

This lab covers **migrating virtual machines between nodes** in an OpenShift Virtualization environment. You performed live migrations with `virtctl` and native Kubernetes resources, monitored migration progress and phases, verified VM functionality and performance afterward, and worked through advanced scenarios and troubleshooting.

> 🧪 **Lab Environment:** OpenShift cluster with OpenShift Virtualization installed. Work is done with the `virtctl` and `oc` CLIs and YAML manifests.

## ✅ Key Accomplishments

In this comprehensive lab, you have successfully learned how to migrate virtual machines between nodes in an OpenShift Virtualization environment. You accomplished several key objectives:

**What You Learned:**

## 🔑 Key Concepts

| 🏷️ Term | 📘 Description |
|---|---|
| **Live Migration** | Moving a running VM between nodes without service interruption |
| **virtctl** | CLI used to trigger live VM migration |
| **Migration Phases** | Stages of a migration, tracked to monitor progress |
| **Batch Migration** | Migrating multiple VMs together |
| **Constraint-Based Migration** | Migration governed by placement constraints |
| **Post-Migration Verification** | Checking VM functionality and performance after a move |
