### 🧩 Core KubeVirt Components

| 🔧 Component | 📖 Role |
|-------------|--------|
| **VirtualMachine (VM)** | The desired state configuration for virtual machines |
| **VirtualMachineInstance (VMI)** | The running instance of a virtual machine |
| **Virt-Launcher** | The pod that actually runs the virtual machine process |

## 🧠 Key Concepts

| 🔑 Concept | 📖 Description |
|-----------|---------------|
| **OpenShift Virtualization** | Capability that extends Kubernetes to run virtual machines alongside containers |
| **KubeVirt** | Set of components that enable virtual machine management on Kubernetes |
| **Operator** | Component that manages the deployment and lifecycle of virtualization services |
| **CDI** | Containerized Data Importer, a supporting component of OpenShift Virtualization |
| **VirtualMachine (VM)** | Custom resource holding the desired state configuration for a virtual machine |
| **VirtualMachineInstance (VMI)** | The running instance of a virtual machine |
| **Virt-Launcher** | Pod that runs the virtual machine process |
| **Custom Resource** | Kubernetes API extension used to define and manage VMs |
