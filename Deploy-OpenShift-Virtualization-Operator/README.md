## 🧠 Key Concepts

| 🔑 Concept | 📖 Description |
|-----------|---------------|
| **OpenShift Virtualization** | Capability for running virtual machines alongside containers on OpenShift |
| **Operator** | Component that deploys and manages the virtualization services |
| **Operator Lifecycle Manager (OLM)** | Mechanism used in this lab to deploy the operator |
| **Custom Resource Definition (CRD)** | API extension that enables virtualization resources |
| **VirtualMachine** | CRD for defining virtual machines |
| **VirtualMachineInstance** | CRD representing a running virtual machine |
| **DataVolume** | CRD for virtual machine data resources |
| **Hybrid Cloud** | Running traditional VM workloads and cloud-native containers together |
